# KoronaTestTask
## Консольное приложение на java которое упорядочивает данные находящиеся в файлах с расширением .sb. В файлах находится информация о сотрудних и менеджерах(*имя и фамилия, зарплата, к какому менеджеру относится сотрудник*), а так же информацию о том к кааким департаментам они относятся. Так же реализована возможность вывода статистики по отделам(*минималная максимальная и средняя запрлата*), Вывод зависит от указанных в командной строке флагах( *вывод в консоль или файл*).Одновременно с этим в проекте реализована возможность  сортировать данные в зависимости от указанных флагов.

## требования
 - java 17
 - Maven 4.0.0
 - Зависимости:
   - **Jcommander 1.8.2** [ссылка на Maven Central](https://search.maven.org/artifact/com.beust/jcommander/1.82/jar)
  
## Сборка и запуск
### Сборка                              
Создать проект с зависмостями:

    mvn clear package
    
В папке target появится JAR-файл со всеми зависимостями: *app-1.0-jar-with-dependencies.jar*
    
### Запуск

Пример запуска приложения:

    java -jar app-1.0-jar-with-dependencies.jar --sort=name --order=asc --stat

## Особенности реализации

- Используется библиотека JCommander для обработки аргументов командной строки.
- Fat JAR собирается через maven-assembly-plugin, чтобы все зависимости были включены.
